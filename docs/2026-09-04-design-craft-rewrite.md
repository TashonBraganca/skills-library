# Design craft rewrite

## Failure to prevent

The skill let an agent fetch a large set of assets, inspect only a small sample, dismiss the corpus,
and ship a generic dashboard with a local font and one weak photograph. Its gate treated any single
real asset as sufficient. Its repeated bans then made the nearest safe visual default feel compliant.

## Design

The skill will teach an art-direction decision rather than prescribe a visual formula. The agent
first studies real references and material candidates. Either may become the lead. A reference can
lead through composition, hierarchy, timing, crop logic, and interaction. An exceptional video,
photograph, model, texture, shader, or component can lead through its own movement, physical form,
light, scale, and behavior.

The agent then selects only material it intends to integrate. A selected item has a named role in the
composition. It does not sit behind the content as a vague effect or occupy a decorative thumbnail.
The agent may change direction when an inspected material gives the page a stronger idea. It does not
fall back to a generic layout because the first candidates were weak.

Every interface needs a focal experience, but its form follows the job. A consumer page may use a
scene or film. An operational tool may make the live object, a temporal state, a command interaction,
or the data itself feel physical and legible. The result must remain usable, accessible, licensed,
and original.

## Boundaries

The rewrite removes fixed aesthetic metrics, required asset categories, fixed palettes, font
preferences, and a broad ban list. It keeps concrete anti-slop guidance as warnings against reflexes,
not forbidden visual styles. It keeps source, licence, contrast, motion, responsive, and build checks.
It does not change the scraper or contrast checker because the evidence points to the agent's
selection behavior, not those tools.

## Validation

The source must state the lead decision, force inspection before a conclusion about material, require
selected material to have a compositional job, allow either reference or asset to lead, and prohibit
copying protected work. A static check will verify those instructions and that obsolete restrictive
rules are gone. A later live model run is still needed to establish behavioral compliance; no such run
will be claimed from a text-only inspection.
