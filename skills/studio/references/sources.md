# Where to hunt references and assets

All checked reachable on 2026-11-19 with a plain fetch unless marked "often blocked" (those pass only
through `ref_board.py`'s stealth retry, if at all). Mobbin and Refero load, but their libraries are
login-walled: use their MCP if connected (ToolSearch "mobbin" or "refero"), never scrape them.

**Never use Unsplash** (owner's rule), not for photos, placeholders or references.
